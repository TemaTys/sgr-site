How the table works

The table renders client-side from assets/data/table.json (218 records, fields documented inside the file itself) — no backend involved. Nothing is filtered out: rows that did not pass every check (permutation test, placebo resampling, or a 95% CI crossing zero) stay in the table and are flagged with a note explaining why on hover. Default sort is by freshness: newest Google Trends findings first, then the original cross-city and single-database set.
